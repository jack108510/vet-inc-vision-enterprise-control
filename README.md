# 01 Enterprise Control

**Intended audience:** Corporate veterinary groups and multi-site operators — specifically the operators, finance leads, and regional managers who own fee-change decisions across multiple clinic locations.

**Design posture:** Most enterprise-first of the three concepts. Deep navy palette (`#0B1623`), structured and operational in tone. Typography-driven with no imagery, no decorative illustration, and no fake metrics. The visual language borrows from audit dashboards and workflow tools — tight grids, monospaced step markers, ruled dividers.

**Positioning emphasis:** Controlled execution at scale. The headline and first section foreground the *process* of implementing approved changes — not choosing prices. The five-step flow (Authorize → Map → Implement → Record → Review) is the visual centrepiece.

**Key guardrails honoured:**
- PMS writeback is explicitly labelled as a planned, contractually governed future capability — not a current live feature.
- No fabricated metrics, testimonials, or customer logos.
- FeeWatch appears as a restrained secondary section (not the primary offer).
- One consolidated scope notice covers integration claims rather than defensive disclaimers throughout.

**Sentinel:** `VISION-CONCEPT-01` (HTML comment in `<head>` + visually-hidden `<span>` in `<body>`).
